# Church events

One Markdown file per event. Start from [the event example](../docs/examples/event.md). `starts_at` and `ends_at` must include a timezone offset. The site lists upcoming and past events using those timestamps at build time.

The two imported 2024 events are archive entries. Their WordPress timezone was UTC+0, so their clock times are hidden pending confirmation. See [migration notes](../docs/migration.md).

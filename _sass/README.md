# Styles

- `_tokens.scss`: brand palette, dimensions, and shared CSS variables.
- `_base.scss`: fonts, type, links, focus, and element defaults.
- `_layout.scss`: containers, grids, pages, and footer.
- `_components.scss`: header/menu, hero, buttons, cards, and event details.

`assets/css/main.scss` loads these modules. Jekyll compiles them to `_site/assets/css/main.css`. Do not edit that generated file. See [design notes](../docs/design.md).

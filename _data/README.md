# Shared church content

Edit these YAML files to update the whole site at once:

- `church.yml`: contact details, Facebook, optional giving/livestream, confirmed service times.
- `home.yml`: homepage welcome, prayer, and visit copy.
- `navigation.yml`: main links in order.
- `leadership.yml`: names, roles, portrait paths, optional Facebook links.
- `ministries.yml`: ministry names and descriptions.
- `services.yml`: service cards and email enquiry subjects.

Use two spaces for indentation, quote values containing colons, and keep internal asset paths starting with `/assets/`. See [the content guide](../docs/content-guide.md).

## Poppins

Regular, SemiBold, and Bold font files came from `themes/fse-spiritual/assets/fonts/poppins/`. Their embedded metadata identifies **Copyright 2020 The Poppins Project Authors** and the **SIL Open Font License 1.1**. This embedded licence takes precedence over the old theme README's inaccurate Apache-font attribution. The matching licence is included in `assets/fonts/OFL.txt`; see [the upstream Poppins licence](https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt).

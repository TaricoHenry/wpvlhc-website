# Public assets

- `css/`: Sass entry point.
- `fonts/`: self-hosted Poppins fonts and their licence.
- `images/church/`: logo, building, and prayer image.
- `images/leadership/`: church leadership portraits.
- `images/services/`: illustrative service-category photos.
- `js/`: progressive mobile navigation.

Use descriptive filenames and keep photos reasonably sized. Public asset paths start with `/assets/`; use `relative_url` in templates for GitHub repository paths. See [asset credits](../docs/asset-credits.md).
